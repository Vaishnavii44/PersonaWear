# 👗 PersonaWear (AI Fashion Universe)

PersonaWear is a full-stack AI-powered virtual wardrobe platform that lets you digitize your closet, create a personalized avatar, and virtually try on clothes using cutting-edge AI (VTON).

## ✨ Key Features
- **Virtual Wardrobe:** Upload and digitize your real-world clothing items.
- **AI Virtual Try-On (VTON):** See how clothes look on you before wearing them.
- **Interactive Avatars:** Powered by React Three Fiber for dynamic posing and styling in a 3D environment.
- **Secure Authentication:** Full user auth and profile management.

## 🛠️ Tech Stack
- **Frontend:** Next.js (React), TailwindCSS, Styled-components, Three.js / React Three Fiber
- **Backend:** Node.js, Express, Prisma (PostgreSQL), Cloudinary (Image storage)
- **AI/ML:** Gradio Client, Generative AI for virtual try-on pipelines
